# Public Name Research — kids-duolingo

**Date:** 2026-08-17
**Context:** Public name for the app currently code-named "kids-duolingo" (working title "Julian's Chinese"). Duolingo-style Mandarin vocab + tap-to-build sentences, plus basic Math, for kids ~4–8. No-punishment philosophy, pack-based content. Launch: free web app, then iOS App Store Kids Category (6–8) at $9.99 one-time.

**Method:** ~10 candidates generated across descriptive / brandable / hybrid. Checks per finalist: (a) App Store + web collisions via web search, (b) .com via whois + .app via RDAP (rdap.org, 404 = unregistered), (c) obvious trademark red flags via web search. Checks run 2026-08-17; domain status changes fast, so re-verify before registering.

**One naming note that shapes everything:** App Store search does not require the keyword in the app *name*. The subtitle and keyword field carry "Chinese for kids", "Mandarin", "math". So a brandable name loses less searchability than it seems, as long as the subtitle does the keyword work (e.g. "Tangram Tots — Chinese & Math for Kids").

## TOP 3 NEW CANDIDATES

### 1. Tangram Tots  ⭐ recommended
- **Why it works:** The tangram is a Chinese puzzle made of geometric shapes — the only candidate that natively bridges Chinese culture AND math in one image. Alliterative, easy for a 5-year-old to say, obvious logo (colorful tangram pieces). "Tots" signals the age band. Doesn't box the app into language-only.
- **App Store:** No app named "Tangram Tots" found. Many generic tangram *puzzle* apps exist (Osmo Tangram, My First Tangrams, Tangram King) but none in language learning and none with this name.
- **Domains:** tangramtots.com AVAILABLE (verified via whois, no match). tangramtots.app AVAILABLE (RDAP 404).
- **Risk notes:** "Tangram" and "tots" are both generic terms; low trademark risk. Mild tension: parents searching "learn Chinese kids" won't guess the name — subtitle/keywords must carry that. Some risk shoppers assume it's a shape-puzzle app; screenshots fix this.

### 2. Mandarin Meadow
- **Why it works:** The descriptive pick. Carries the "Mandarin" keyword in the name itself (best raw App Store searchability of the three), while "Meadow" keeps it soft, kid-safe, and brandable — a gentle world rather than a curriculum. Fits the no-punishment philosophy.
- **App Store:** No app by this name found. The Mandarin-kids space is crowded (Studycat, Miaomiao's Chinese, Maomi Stars, HelloChinese) but no name collision.
- **Domains:** mandarinmeadow.com AVAILABLE (whois, no match). mandarinmeadow.app AVAILABLE (RDAP 404).
- **Risk notes:** Low trademark risk (generic + generic). Real tension: the name says language-only, so Math reads as a bonus feature, not a pillar. If Math ever becomes a headline feature, this name fights it. Also longest of the three (15 chars).

### 3. Bamboo Buddies
- **Why it works:** Fully brandable and math-neutral. Bamboo cues China without naming the language, "Buddies" cues friendly/no-punishment, and it supports a mascot cast (panda + friends) without stepping into the overcrowded "Panda ___" naming space. Room to grow into any subject.
- **App Store:** No app named "Bamboo Buddies" found. The panda/bamboo kids category is dominated by big franchises (Dr. Panda, BabyBus's "Baby Panda" line) — adjacent, but no name conflict.
- **Domains:** bamboobuddies.com TAKEN (registered 2014, parked on CashParking — possibly buyable cheap, currently unused). bamboobuddies.app AVAILABLE (RDAP 404).
- **Risk notes:** Low trademark risk. Weakest raw searchability of the three — zero keywords in the name, subtitle must do all the work. .com not free is the main knock; getbamboobuddies.com or the .app would do for a web launch.

## VERDICTS ON EXISTING CANDIDATES

### Little Mandarin — AVOID (high risk)
- **App Store collision:** Two live apps are already named exactly "Little Mandarin": a class-booking app by Momence (id6741390186) and "Little Mandarin Yoga & Pilates" (id1261371274). Apple also rejects Kids Category names that duplicate existing app names too closely.
- **Trademark red flag (the real problem):** "LittleMandarin Chinese School®" is a registered brand of Mandarin Education GmbH (Switzerland) operating in exactly this space — Mandarin education for young children. There is also a "Little Mandarin Academy" in Brooklyn, and at least one school already *rebranded away* from the "Little Mandarin" name (mandoschool.com blog). Same name, same services, same customers = the bad kind of trademark overlap.
- **Domains:** littlemandarin.com TAKEN — parked for sale at DomainMarket (premium pricing). littlemandarin.app AVAILABLE, which doesn't rescue the rest.
- **Also:** name excludes Math entirely.

### Panda Packs — USABLE BUT NOISY (medium risk, not recommended)
- **App Store collision:** No kids-education conflict, but "Panda Pack" (singular) is a live iMessage sticker app (id1154575089), and "Panda Pack" is also used by Panda Planner (productivity bundle), pandapack.io, pandaspacks.com, and a Pioneer backpack product. Search results for the name are a grab bag.
- **Trademark:** No single blocking mark found, but the name has no distinctive ground to defend — "Panda ___" is the most crowded naming pattern in kids' apps (Dr. Panda, Baby Panda/BabyBus, Little Panda...).
- **Domains:** pandapacks.com TAKEN (NameBright, registered 2016 — likely a for-sale hold). pandapacks.app AVAILABLE.
- **Verdict:** Launchable without a lawsuit, but it buys the worst of both worlds: no search keywords AND no clean brand space. The "packs" concept is an internal data model, not a parent-facing hook.

## RECOMMENDATION

**Tangram Tots**, with the App Store subtitle carrying the keywords ("Chinese & Math for Kids"). It is the only name that honestly covers both subjects, both domains are unregistered as of today, the App Store slot is empty, and the trademark surface is two generic words. Register tangramtots.com and tangramtots.app immediately (combined ~$35/yr) even if the final decision waits — Mandarin Meadow's pair is worth the same $35 hedge if undecided.

**Before committing:** run a USPTO TESS search on the final pick (web search found no flags, but TESS wasn't queried directly), and search the exact name in the App Store app on a device — Apple's search surfaces some apps that web search misses.
