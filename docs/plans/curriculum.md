# Mandarineer Curriculum — Full Content Design

Source: Jenny's spoken braindump (2026-08-19, Chinese transcript archived at bottom) +
current app content (13 packs / ~183 words). This document is the canonical content
roadmap: every category she named is mapped to a pack, organized into levels a
4–8-year-old can climb.

Design rules:
- **8–14 words per pack** (one session = 8 questions; a pack ≈ 1–2 sessions to see everything).
- **Nouns you can point at come first; words that glue sentences come last.**
- Levels are *guidance, not gates* — no-punishment philosophy extends to navigation;
  everything stays tappable, levels organize the shelf.
- Every word ships with: english, hanzi, pinyin, emoji (interim) → illustration (later), audio (Phase 3 pipeline picks up new words automatically).
- Measure words (只/条/个/辆) are taught **inside sentence patterns**, not as isolated flashcards — exactly how Jenny spoke them.

## Sentence Tracks (tap-to-build, one per level)

Jenny's spoken examples ARE the pattern spec — she naturally produced measure words
and color-in-noun-phrase constructions:

| Track | Level | Patterns | Her examples |
|-------|-------|----------|--------------|
| S1 · This Is… | L1 | 这是一只X · 一只/一条/一个 + noun · number+measure+noun | 这是一条狗 · 一只猫 · 两条狗 · 三只火箭 |
| S2 · Colors & Counts | L2 | color inside noun phrase · 我有X · 我是X | 一只蓝色的鸟 · 我是一只猫咪 · 许多鱼 |
| S3 · Where & Have | L3 | X在哪里 · X在Y上/里 · 我要去X | 谁在哪里 |
| S4 · Real Talk | L4 | 你叫什么名字 · 你几岁 · 你从哪里来 · 这是什么 · 我想要X · 你可以X吗 · 今天天气… | direct from transcript |

Measure-word engine note: sentence tiles teach 只(animals) 条(long animals) 个(general)
辆(vehicles) 本(books) implicitly by always pairing correctly — never as abstract rules.

## Stories Track (future, Phase F)

她 asked for 故事书: 6–10-screen tap-through picture stories using ONLY words the child
has already met (comprehensible input). Each screen: illustration + one sentence, tap
any word to hear it. First three: "小猫找妈妈" (animals+family), "红色在哪里?" (colors),
"我的一天" (routines). Design after L1–L2 packs ship.

## Product changes this requires

1. **Packs page → leveled journey.** 41 packs can't be a flat list. Group by level with
   the Sunrise Playground treatment: each level a "region" on the hillside (L1 sunrise
   meadow → L4 mountain top), packs as stepping stones. Mastery rings intact.
2. **Pack size guardrail**: seed script warns if a pack exceeds 14 words.
3. **Data pipeline unchanged**: packs stay JSON in data/packs/ → seed → generate-questions
   → audio script (Phase 3) picks up new vocab automatically. Sentences JSON per track.
4. **Native review loop**: content lands as PR-able JSON diffs; Jenny (native speaker)
   reviews hanzi/pinyin/naturalness before seed. Pinyin with tone marks everywhere.
5. **Math bridge** (差异化!): counting exercises can speak Chinese (三 + 🚀🚀🚀) —
   the "math in Mandarin" differentiator no competitor has. Design when Big Numbers ships.
